Below is a **minimal‑but‑complete** front‑end that incorporates all of 
the improvements we discussed.  
Everything is vanilla JS/CSS – no bundler required – but the code is 
split into three files so it’s far easier to read, test, and maintain.

```
/project-root
├─ index.html
├─ style.css
├─ app.js
└─ README.md
```

> **Why this layout?**  
> * `index.html` is the only file the browser loads – it pulls in 
Tailwind, DOMPurify, the CSS and the JS.  
> * `style.css` contains only the tiny bits that Tailwind doesn’t cover 
(toast container, spinner, drop‑zone).  
> * `app.js` holds all the logic (state, event handling, API calls, UI 
rendering).  
> * `README.md` tells you how to run it locally (no npm, just a static 
file server).

## 3️⃣ app.js

```js
/* =========================================================
   Simple front‑end for a streaming chat + context upload
   ========================================================= */

/**
 * Global immutable state (you can replace this with a proper state lib 
if you wish)
 */
const UI = (() => {
  // default state
  const DEFAULT = {
    context: [],          // [{id, name, type, size, preview}]
    messages: [],         // last 20 messages
    loading: false,
  };

  // helpers to persist context in localStorage
  const STORAGE_KEY = 'uploadedContext';

  const loadState = () => {
    try {
      const stored = localStorage.getItem(STORAGE_KEY);
      return stored ? JSON.parse(stored) : [];
    } catch (_) {
      return [];
    }
  };

  const saveState = (ctx) => {
    try {
      localStorage.setItem(STORAGE_KEY, JSON.stringify(ctx));
    } catch (_) {}
  };

  // current context (array of file descriptors)
  let context = loadState();

  // current AbortController (used for cancel)
  let currentAbort = null;

  return {
    /** @returns {Array} current context */
    getContext: () => context,

    /** @param {Array} newCtx */
    setContext: (newCtx) => {
      context = newCtx.slice();   // immutable copy
      saveState(context);
      renderContext();
    },

    /** Push a new message – keeps a maximum of 20 */
    pushMessage: (msg) => {
      if (UI.getMessages().length >= 20) {
        UI.getMessages().shift();
      }
      UI.getMessages().push(msg);
      renderChat();
    },

    /** @returns {Array} all chat messages */
    getMessages: () => DEFAULT.messages,

    /** Enable or disable the send button */
    setLoading: (isLoading) => {
      DEFAULT.loading = isLoading;
      document.getElementById('send-btn').disabled = isLoading;
      document.getElementById('cancel-btn').classList.toggle('hidden', 
!isLoading);
      document.getElementById('spinner').classList.toggle('hidden', 
!isLoading);
    },

    /** Notify the user (toasts) */
    notify: (msg, type = 'info') => {
      const el = document.createElement('div');
      el.className = `toast ${type}`;
      el.textContent = msg;
      document.getElementById('toast-container').appendChild(el);

      // auto‑dismiss after 4 s
      setTimeout(() => el.remove(), 4000);
    },

    /** Show error in the console and as a toast */
    handleError: (err) => {
      console.error(err);
      UI.notify(`Error: ${err.message || err}`, 'error');
    },
  };
})();

/* =========================
   UI Rendering helpers
   ========================= */

const renderContext = () => {
  const container = document.getElementById('context-list');
  container.innerHTML = ''; // reset

  UI.getContext().forEach((file) => {
    const badge = document.createElement('div');
    badge.className = 'flex items-center gap-1 text-sm px-2 py-1 
bg-gray-200 rounded hover:bg-gray-300 cursor-pointer';
    badge.title = file.name;

    // thumbnail or truncated preview
    if (file.type.startsWith('image/')) {
      const img = document.createElement('img');
      img.src = file.data;
      img.alt = file.name;
      img.className = 'w-6 h-6 object-cover rounded';
      badge.appendChild(img);
    } else {
      const txt = document.createElement('span');
      txt.textContent = file.data.slice(0, 40) + (file.data.length > 40 ? 
'…' : '');
      badge.appendChild(txt);
    }

    // click → preview
    badge.addEventListener('click', () => showFilePreview(file));

    // remove button
    const rm = document.createElement('button');
    rm.textContent = '✕';
    rm.className = 'text-gray-500 hover:text-gray-800';
    rm.setAttribute('aria-label', `Remove ${file.name}`);
    rm.addEventListener('click', (e) => {
      e.stopPropagation();
      UI.setContext(UI.getContext().filter((_, i) => i !== file.idx));
    });

    badge.appendChild(rm);
    container.appendChild(badge);
  });
};

const renderChat = () => {
  const chat = document.getElementById('chat');
  chat.innerHTML = ''; // clear

  UI.getMessages().forEach((msg) => {
    const div = document.createElement('div');
    div.className = 'p-2 border rounded';
    div.setAttribute('role', 'article');
    div.setAttribute('aria-live', 'polite');

    if (msg.role === 'user') {
      div.innerHTML = `<strong>You:</strong> 
${DOMPurify.sanitize(msg.content)}`;
    } else {
      div.innerHTML = `<strong>AI:</strong> 
${DOMPurify.sanitize(msg.content)}`;
    }

    chat.appendChild(div);
  });

  // scroll to bottom
  chat.scrollTop = chat.scrollHeight;
};

const showFilePreview = (file) => {
  const modal = document.createElement('div');
  modal.className = 'fixed inset-0 bg-black bg-opacity-50 flex 
items-center justify-center';
  modal.setAttribute('role', 'dialog');
  modal.setAttribute('aria-modal', 'true');

  const box = document.createElement('div');
  box.className = 'bg-white p-4 rounded shadow-lg max-w-3xl w-11/12';
  if (file.type.startsWith('image/')) {
    const img = document.createElement('img');
    img.src = file.data;
    img.alt = file.name;
    img.className = 'max-w-full';
    box.appendChild(img);
  } else {
    const pre = document.createElement('pre');
    pre.textContent = file.data;
    pre.className = 'whitespace-pre-wrap';
    box.appendChild(pre);
  }

  const close = document.createElement('button');
  close.textContent = 'Close';
  close.className = 'mt-4 px-4 py-2 bg-indigo-600 text-white rounded';
  close.addEventListener('click', () => modal.remove());

  box.appendChild(close);
  modal.appendChild(box);
  document.body.appendChild(modal);
};

/* =========================
   File upload handling
   ========================= */

/**
 * Accept only .txt, .json, .jsonl, images, and PDF (converted to text)
 * @param {File} f
 */
const processFile = (f) => {
  const allowedTypes = ['text/plain', 'application/json', 
'application/jsonl', 'image/', 'application/pdf'];
  if (!allowedTypes.some((t) => f.type.startsWith(t))) {
    UI.notify(`Unsupported file type: ${f.name}`, 'warn');
    return;
  }

  const reader = new FileReader();

  reader.onload = (ev) => {
    const idx = UI.getContext().length; // index for removal
    const data = ev.target.result;

    const desc = {
      idx,
      name: f.name,
      type: f.type,
      size: f.size,
      data: data,
    };

    UI.setContext([...UI.getContext(), desc]); // add to context
  };

  if (f.type.startsWith('image/')) {
    reader.readAsDataURL(f);
  } else {
    reader.readAsText(f);
  }
};

/**
 * Drop‑zone event listeners
 */
const dropZone = document.getElementById('drop-zone');
dropZone.addEventListener('dragover', (e) => {
  e.preventDefault();
  dropZone.classList.add('dragover');
});
dropZone.addEventListener('dragleave', () => 
dropZone.classList.remove('dragover'));
dropZone.addEventListener('drop', (e) => {
  e.preventDefault();
  dropZone.classList.remove('dragover');

  Array.from(e.dataTransfer.files).forEach(processFile);
});

/* =========================
   Chat form submission
   ========================= */
const chatForm = document.getElementById('chat-form');
chatForm.addEventListener('submit', async (e) => {
  e.preventDefault();
  const inp = document.getElementById('chat-input');
  const text = inp.value.trim();
  if (!text) return;

  // push user message
  UI.pushMessage({ role: 'user', content: text });
  inp.value = ''; // clear

  // start streaming AI response
  UI.setLoading(true);

  try {
    // The backend must support SSE; the URL may need to change
    const response = await fetch('/chat', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        user: text,
        context: UI.getContext(),
      }),
      signal: (currentAbort = new AbortController()).signal,
    });

    if (!response.ok) throw new Error(`HTTP ${response.status}`);

    // Stream SSE events
    const reader = response.body.getReader();
    const decoder = new TextDecoder('utf-8');
    let buffer = '';

    // Keep receiving until finished
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });

      // parse SSE chunks (simple, no retry logic)
      const lines = buffer.split('\n');
      buffer = lines.pop(); // last (maybe incomplete) chunk

      lines.forEach((line) => {
        if (!line.trim()) return;
        if (line.startsWith('data:')) {
          const data = line.slice(5).trim();
          // AI content
          UI.pushMessage({ role: 'assistant', content: data });
        }
      });
    }

    UI.notify('Done', 'success');
  } catch (err) {
    if (err.name === 'AbortError') {
      UI.notify('Request cancelled', 'warn');
    } else {
      UI.handleError(err);
    }
  } finally {
    UI.setLoading(false);
  }
});

/* Cancel button */
document.getElementById('cancel-btn').addEventListener('click', () => {
  if (currentAbort) currentAbort.abort();
  UI.setLoading(false);
  UI.notify('Request cancelled', 'warn');
});

/* =========================
   Initialize
   ========================= */
document.addEventListener('DOMContentLoaded', () => {
  renderContext();  // show any stored context
});
```

**What changed?**

1. **XSS Protection** – `DOMPurify.sanitize()` now surrounds every 
user/assistant content before inserting into the DOM.
2. **Error handling** – all fetch errors are caught and shown as toasts.
3. **AbortController** – allows cancellation of the current streaming 
request (`Cancel` button).
4. **LocalStorage** – context is persisted across page reloads.
5. **Clean UI** – the `Send` button becomes disabled when a request is in 
flight, and the `Cancel` button appears.

## 4️⃣ Minimal Backend

You mentioned that your backend is a simple FastAPI (or equivalent) that 
returns a streaming response with a **SSE** format.  
Below is a minimal example in **FastAPI** (Python).  
> *If you’re using another stack, adapt the endpoints accordingly.*

```python
# main.py
from fastapi import FastAPI, Request
from fastapi.responses import StreamingResponse
import json
import asyncio

app = FastAPI()

@app.post("/chat")
async def chat(request: Request):
    data = await request.json()
    user_msg = data.get("user")
    context = data.get("context", [])

    # (Your LLM logic goes here; for demo we just echo back)
    async def event_generator():
        yield f"data: Received: {user_msg}\n\n"
        await asyncio.sleep(0.5)
        # pretend the model sends a streaming response
        for i in range(5):
            yield f"data: Chunk {i+1}\n\n"
            await asyncio.sleep(0.5)

    return StreamingResponse(event_generator(), 
media_type="text/event-stream")
```

> **Important** – The SSE response must end with two newlines (`\n\n`) 
after every message chunk.

## 5️⃣ Quick Deployment

- **Frontend** – Place the three files in the root of a static web server 
(`index.html`, `style.css`, `app.js`).
- **Backend** – Run the FastAPI app (or your own implementation) on the 
same host or a separate server.  
  Make sure the endpoint (`/chat`) matches the URL used in `app.js`.
- **CORS** – If your backend is on a different origin, enable CORS.

```bash
uvicorn main:app --reload
```
