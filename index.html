Getting Started

Standard Workflow

1

Install a Model

Go to the Settings (⚙️) tab. Use the "Browse Ollama" button to find a model name (e.g., llama3.2 or deepseek-coder). Enter it in the Download Manager and click Queue. Wait for the green "Installed" status.

2

(Optional) Add Knowledge

In the Chat (💬) tab sidebar, click + Files to upload text, code, or PDFs. The content of these files will be automatically injected into the AI's context window (RAG).

3

Select & Chat

Select your installed model from the dropdown in the Sidebar. Type your prompt and hit Send. Use the Stop button if the model gets stuck.

Advanced Features

🧪 Model Lab

You can create custom "Personas" without downloading new files.
1. Go to Settings > Model Lab.
2. Load a base model (e.g., llama3).
3. Edit the SYSTEM prompt to say "You are a pirate."
4. Save as llama-pirate.
5. It will appear instantly in your chat dropdown.

🛑 Stop Button

The Stop button uses a real hardware signal. Clicking it immediately cuts the connection to the Ollama engine, freeing up your GPU VRAM instantly.

Troubleshooting

  • Model not responding? Check the "Hardware" status in the top bar. If it's stuck, restart the backend.
  • Gemma showing <unused>? This version of WebOlla automatically scrubs these special tokens. If you see them, check for updates.
  • Context Limit: If the model forgets early parts of the conversation, increase the Ctx slider in the sidebar (uses more VRAM).
